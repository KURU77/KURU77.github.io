主要作品 Selected Works

研究デスク

研究ごとに、先行研究・費用・進捗・予定と、電子部品・工具の台帳をまとめて管理するアプリ

作った理由
研究の動機・目標・予定を忘れないよう書き留めておくとともに、実験のために作るデバイスの設計や進捗、部品の残り数まで、一か所で管理したかったため。
主な機能
  • 研究ごとに概要・先行研究とデータセット・費用・進捗・予定を管理。DOI・arXiv のURL・BibTeX を貼ると書誌を自動入力
  • 電子部品・工具・計測器の台帳。研究で記録した費用から台帳へ自動で追加し、未使用／使用中／使用済みの数を管理
  • 自作実験装置の仕様書・手順書。Word・PDF・LaTeX などの資料を読み取って項目に振り分ける
技術
  • HTML/CSS/JavaScript（依存ライブラリなし）
  • PWA
  • localStorage・IndexedDB
  • Google Drive API・OAuth
  • CrossRef API
  • pdf.js
工夫した点
  • Word（.docx）を外部ライブラリなしで読むため、ブラウザ標準の展開機能（DecompressionStream）で中身を取り出して解析
  • 資料中の LaTeX 記法（例：\SI{120}{\milli\ampere} → 120 mA）をふつうの文字に変換して取り込む
  • 端末間の同期を項目1件ずつマージし、オフライン中に別の端末で編集しても両方の変更が残るようにした

積読シェルフ

読む予定の論文を優先度つきの「棚」にまとめ、次に読む一本をすぐ決められるアプリ

作った理由
以前はスマホのファイルアプリで論文を保存していたが、どれを読んでいるのか分からない、保存のたびに新しいフォルダを作ってしまう、どの論文がどんな内容だったかすぐに思い出せない、といった不便を解消するため。
主な機能
  • 論文のURL・DOI・BibTeX・RIS・タイトルを貼るだけで書誌を自動入力
  • ホームに「次の一本」（読書中、なければ優先度が最も高い未読）を表示。積んでからの日数を表示し、30日を超えると色で知らせる
  • タイトル・著者・掲載先・タグ・メモの横断検索。JSON と BibTeX で書き出し
技術
  • HTML/CSS/JavaScript（依存ライブラリなし）
  • PWA
  • localStorage
  • Crossref・DataCite・OpenAlex・Semantic Scholar API
工夫した点
  • DOI・arXiv ID・PMID を取り出して複数の公開APIに順に照会し、1つで足りない項目だけを次の候補で埋める
  • Nature・ACL Anthology などはURLの形からDOIを組み立てる。識別子が取れないときはタイトル検索に切り替え、「確認してください」と表示
  • 照会で送るのは識別子か検索語だけ。設定で通信なしの解析だけに切り替えられる

資格・検定トラッカー

取りたい資格・検定をリスト化し、目標スコアと受験記録を管理するアプリ

作った理由
興味のある資格・検定の情報をまとめて記録し、それぞれの公式サイトへ簡単にアクセスできるようにするため。また、まだ知らない資格・検定を調べられるようにするため。
主な機能
  • 資格名を入力すると約1,400件のプリセットから候補を表示し、カテゴリ・目標スコア・受験料などを自動入力（かな・ローマ字でも検索可）
  • 受験日ごとにスコアと合否を記録し、最高スコアと目標達成率を進捗バーで表示。試験日までの残り日数も表示
  • Google アカウントでログインすると、iPhone・iPad・PC の間でリストを同期
技術
  • HTML/CSS/JavaScript（ビルド不要）
  • PWA
  • localStorage
  • Google Drive API・OAuth
工夫した点
  • プリセットは Wikipedia と資格情報サイトの一覧を突き合わせて作成し、合格基準・受験料は確認できた範囲だけを収録
  • 同期データは利用者自身の Google ドライブのアプリ専用領域に保存し、サーバーを使わない構成にした
  • 同期がぶつかったときは資格ごとに新しいほうを採用し、削除した時刻も記録して、消したものが復活しないようにした
