所得シミュレーター

income-tax-simulator-jp

共通していること

  • データは端末の中だけ — 入力した内容はブラウザの localStorage や端末内のファイルに保存され、サーバーには送信しません。JSONでの書き出し／読み込みに対応しているものが多いです。
  • アカウント登録なし・インストール不要 — リンクを開けばその場で使えます。
  • スマホ前提の作り — iPhone で「ホーム画面に追加」するとアプリのように全画面で使え、多くはオフラインでも動きます。入力欄で画面が勝手に拡大しないようにしてあります。
  • ビルド不要の構成が中心 — 多くは HTML / CSS / JavaScript だけで、フレームワークもビルドツールも使っていません（「自炊ごはん記録」だけ React Native / Expo）。
